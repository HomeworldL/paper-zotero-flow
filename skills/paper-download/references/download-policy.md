# Download Policy

Try direct arXiv, Unpaywall, OpenAlex, explicit public publisher or repository links, then authorized Edge. Unpaywall needs a contact email but no API key. OpenAlex needs no key.

Require `%PDF-`, at least 10 KiB, SHA-256, and identity agreement. Provider candidates tied to a canonical record carry trusted identity; explicit and browser files require agent confirmation from the PDF itself.

Delete partial downloads and invalid temporary files. Never use unauthorized repositories, bypass a paywall, extract credentials, or automate institutional login.
